# Creature Collector — Ideas Catalogue

A running collection of creative ideas for the new Zone 2–first creature-collecting cycling game. This is a **separate game** from Cycle Quest.

## Game name ideas

### Favorites — shortlisted October 30, 2026

| Name | Notes |
| --- | --- |
| **Pedalkin** | Friendly and clearly cycling-adjacent; could also describe the creatures. |
| **Milelings** | Little companions discovered mile by mile; strong creature-family naming potential. |
| **Spokelings** | Whimsical creature name with a subtle bike connection. |
| **Wildkin** | Nature-forward, broader creature-collector identity without an overt cycling reference. |

All four are **equally shortlisted**, not ranked or selected as the final game name.

### Next steps
- Explore additional name candidates as they arise.
- Eventually check trademark, existing game uses, and domain availability before selecting a final name.

## Gameplay direction (context only)
Long Zone 2 rides become enjoyable through exploration, discovery, and befriending creatures. Creatures have personalities and Wildness/Patience capture mechanics. Routes and trainer resistance continue normally during encounters; Chaotic creatures are rare optional brief hard-effort challenges. Companion progression is based on companionship rather than combat XP.

See [creature-collector-zone2.md](./creature-collector-zone2.md) for the current design contract.
