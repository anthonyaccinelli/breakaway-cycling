# Breakaway Cycling v3.5.1 — Visible grade colors

The main Chrome elevation chart now displays grade-colored terrain in addition to the always-on-top overlay.

Green: <=6%; orange: >6% to 12%; red: >12% to 18%; purple: >18%. Descents are green.

If an older server is already running, quit it first using `Stop GPX Virtual Trainer.command` and `Stop Overlay.command`, then start this release.

To see orange/red/purple, generate or edit terrain with grades above 6%. Low-ascent routes may be entirely green.
