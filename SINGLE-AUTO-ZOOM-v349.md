# Breakaway Cycling v3.4.9 — Single Automatic-Zoom Elevation Profile

One elevation profile in the always-on-top overlay.

- Fixed-distance/generated routes and imported GPX: entire route shown by default.
- Endless routes: 5-mile rider-centered view by default (future terrain is not yet generated).
- At 6% gradient or steeper for 1.2 seconds: zoom to 1 mile centered on rider.
- Below 5% gradient for 2.5 seconds: return to the default view.
- 5–6% gradients retain the existing zoom state to prevent flickering.
- Yellow rider marker tracks distance in whichever view is displayed.
- Custom metric readouts and other v3.4.8 features are unchanged.

Launch with `Start GPX Trainer with Overlay.command`. The update has not been tested on physical trainer hardware.
