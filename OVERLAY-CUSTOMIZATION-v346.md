# Breakaway Cycling v3.4.6 — Custom overlay readouts

In the Ride Dashboard, check any number of metrics under **Always-on-top overlay readouts**. Use Select all or Select none as desired. The selection persists in Chrome localStorage and is transmitted to the local Electron overlay with the existing telemetry snapshot. The overlay dynamically renders the selected cards, including newly available elapsed time, 3-second power, total ascent, calories, and beers earned. No metrics are required; an empty selection keeps the elevation profile and footer visible.

The main Ride Dashboard is unchanged. The elevation graph remains independently visible in the overlay. This release retains v3.4.5 physics, Zwift Click keepalive, and the original Chrome + Electron helper launcher.
